# توثيق خط إنتاج الكتاب التجميعي السابق (Legacy Book Generation Pipeline)

## الغرض من هذا المجلد
يحتوي هذا المجلد على لقطات توثيقية وأرشيفية لمشروع إنتاج "موسوعة مطور Microsoft Power Platform و Dynamics 365 العربية" التي كان يجري توليدها آلياً عبر أدوات Python (`crawl.py`, `validate.py`, `build.py`, `test_pipeline.py`) من مئات وحدات Microsoft Learn ومختبرات GitHub.

## سبب الأرشفة والتحول المعماري
في نوفمبر 2026، تم تغيير الهدف الاستراتيجي للمشروع:
1. **الانتقال من التوثيق النظري إلى الاحتراف البرمجي العملي:** لم يعد الهدف ترجمة 447 وحدة ترجمة حرفية أو سطحية، بل بناء بيئة تعلم وتطوير تفاعلية تمكّن المهندس من بناء حلول Dataverse مؤسسية حقيقية، وكتابة إضافات C# Plug-ins قوية، والتكامل مع Azure و .NET، والاستعداد لاختبار AB-400.
2. **علاج مشكلة الترجمة الحرفية:** كانت الترجمات السابقة تعاني من أساليب ركيكة وترجمة كلمة بكلمة لبعض المفاهيم البرمجية (مثل "يطلق شرارة تشغيله" أو "موطنها الفيزيائي").
3. **وضع أدوات البناء السابقة كأدوات ثانوية:** لا نزال نحتفظ بملفات `build.py` و `validate.py` و `test_pipeline.py` داخل `book/tools/` كأدوات تدقيق ودعم عند الحاجة، ولكن تم تحرير خطة العمل من قيود تنسيق وتوليد ملفات PDF الضخمة لصالح كتابة الكود وبناء معرض الأعمال.

## محتويات الأرشيف
- `translated-v3-snapshot/`: نسخة طبق الأصل من ملفات الترجمة الأربعة (Pilot units) كما كانت قبل انطلاق مرحلة المراجعة التحريرية الشاملة.
- `pilot-builds/`:
  - `pilot-preview.v1-broken.html` و `pilot-preview.v1-broken.pdf`: النسخة المعيبة الأولى قبل إصلاح معالجة الرموز.
  - `pilot-preview.v3-pre-editorial.html` و `pilot-preview.v3-pre-editorial.pdf`: النسخة التجميعية المستقرة آلياً قبل إعادة الصياغة اللغوية.

## كيفية استخدام الكود الأصلي والمواد
- تظل ملفات المصدر الإنجليزية الأصلية محفوظة بصورة دائمة في `book/original/`.
- تظل أكواد المعامل الرسمية محفوظة في `book/labs-code/`.
- يتم استخدام المقتطفات والوحدات المعتمدة كمدخلات لمجلدات المعامل `labs/` ومذكرات الفهم الهندسي `learning/notes/`.
