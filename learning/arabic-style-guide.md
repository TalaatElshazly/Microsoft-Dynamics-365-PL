# دليل الأسلوب العربي للتوثيق والتعليم التقني (Arabic Technical Style Guide)

## الرؤية والهدف
توفير مرجع تحريري وهندسي ملزم لصياغة المحتوى والشروحات التقنية باللغة العربية داخل مساحة عمل تطوير Microsoft Power Platform & Dataverse. الهدف هو تقديم محتوى عربي فصيح، طبيعي، ودقيق هندسياً يُخاطب مهندس برمجيات محترف (خاصة من خلفية .NET / C#)، ويتجنب تماماً الترجمة الحرفية الركيكة، ويحافظ على سلامة المصطلحات البرمجية الإنجليزية الرسمية دون تشويه.

---

## 1. المبدأ الأساسي: المعنى الوفي والصياغة الطبيعية
- **نقل المعنى والوظيفة وليس مجرد الكلمات:** لا نترجم بنية الجملة الإنجليزية كلمة بكلمة، بل نعيد بناء الجملة بالتركيب العربي الفصيح الذي يوصل الفكرة الهندسية بدقة وسلاسة.
- **التوازن بين العربية والمصطلحات التقنية:** لا نعرب المصطلحات البرمجية القياسية التي يؤدي تعريبها إلى غموض أو تعقيد (مثل Plug-in، Execution Pipeline، IOrganizationService، Custom API، Solution Layers، Sandbox)، بل نبقيها بالإنجليزية ونوضح دورها المعماري بالعربية عند الورود الأول.

---

## 2. قواعد الصياغة الذهبية

### أ. تجنب الترجمات الحرفية والتعبيرات الركيكة (Literal Translation Anti-Patterns)
| التعبير الحرفي الركيك (مرفوض) | التعبير الفني العربي السليم (معتمد) | السبب الهندسي واللغوي |
| :--- | :--- | :--- |
| ما الذي يطلق شرارة تشغيله (What starts it running) | ما الذي يُحفّز تشغيله / شروط إطلاق تنفيذه | في هندسة البرمجيات نتحدث عن المحفزات (Triggers) وشروط بدء المعالجة وليس إطلاق الشرر. |
| موطنها الفيزيائي (Physical home) | مكان التنفيذ الفعلي / بيئة الاستضافة والحوسبة | بيئات التشغيل البرمجية لا توصف بـ "موطن فيزيائي"، بل ببيئة الاستضافة (Host Environment) أو مكان المعالجة (Execution Target). |
| لا يتم شحن المفاتيح مع الملفات (Aren't shipped with) | لا تتضمن ملفات المعمل المفاتيح مسبقاً | "شحن" ترجمة آلية لكلمة ship البرمجية؛ والأصح أنها لا تأتي مدمجة أو غير مرفقة. |
| فحص يقتصر على أن يقول لا مبكراً (Say no early) | فحص يهدف إلى رفض العملية مبكراً بأقل تكلفة | التعبير الإنجليزي مجازي عام؛ والتعبير التقني العربي يحدد رفض المعاملة بأقل استهلاك لموارد النظام. |
| تسقط في خطافات المنصة (Hook into) | ترتبط بنقاط التوسيع في المنصة / تتكامل عبر خط الأنابيب | الترجمة الحرفية لـ hooks مشوهة للمعنى؛ والمقصود نقاط التوسيع (Extension Points) أو معالجات الأحداث (Event Handlers). |

### ب. استخدام الفعل المبني للمعلوم والتركيب المباشر
- تجنب الإفراط في صيغ المبني للمجهول المترجمة حرفياً (مثل: "تم القيام بإنشاء الكود من قبل المطور").
- استبدلها بالجملة المباشرة القوية: "أنشأ المطور الفئة البرمجية" أو "تُنشئ أداة PAC CLI ملفات المشروع".

### ج. علامات الترقيم وتنسيق النصوص ثنائية الاتجاه (BiDi)
- ضع مسافة دائماً بين الكلمة العربية والكلمة الإنجليزية أو رمز الكود.
- احتفظ بأسماء الأصناف والدوال والمعاملات داخل وسوم الكود المضمن `` `code` `` أو وسوم العزل الاتجاهي `<bdi class="en-term" dir="ltr">term</bdi>`.
- تجنب تراكم الأقواس التفسيرية في كل سطر؛ اذكر المصطلح الإنجليزي في سياق الجملة بسلاسة دون تشويش تدفق القراءة.
