## مسارات التعلم الرسمية (Official Learning Paths)

### 1. توسيع Dataverse بالكود وحوسبة Azure (`learn.wwl.extend-dataverse-code-azure`)
- **الموديول 1:** `learn.wwl.get-started-power-platform-development` — بدء التطوير البرمجي وتحديد بيئات التشغيل.
- **الموديول 2:** `learn.wwl.implement-dataverse-plug-ins` — بناء إضافات C# Plug-ins والتعامل مع خط الأنابيب.
- **الموديول 3:** `learn.wwl.harden-dataverse-extensions` — تحصين الإضافات وتطبيق الهوية المدارة وأمان الذاكرة.
- **الموديول 4:** `learn.wwl.perform-dataverse-api-operations` — تنفيذ عمليات CRUD والاستعلامات عبر Web API و SDK.
- **الموديول 5:** `learn.wwl.diagnose-dataverse-api-failures` — تشخيص أخطاء API وسياسات إعادة المحاولة المرنة.
- **الموديول 6:** `learn.wwl.process-workloads-azure-functions` — معالجة الأحمال طويلة الأمد عبر Azure Functions.

### 2. بناء تجارب مستخدم احترافية في Power Apps (`learn.wwl.build-power-apps-experiences`)
- **الموديول 1:** `learn.wwl.build-dataverse-code-apps` — بناء تطبيقات الكود المستقلة على Dataverse.
- **الموديول 2:** `learn.wwl.connect-code-apps-platform-services` — ربط تطبيقات الكود بخدمات المنصة.
- **الموديول 3:** `learn.wwl.deploy-operate-code-apps` — نشر وتشغيل ومراقبة تطبيقات الكود.
- **الموديول 4:** `learn.wwl.apply-client-logic-model-driven-apps` — برمجة منطق العميل عبر Client API و JavaScript.
- **الموديول 5:** `learn.wwl.build-power-apps-component-framework-code-components` — بناء مكونات PCF تفاعلية بـ TypeScript و React.

### 3. بناء الأتمتة وتكاملات وكلاء الذكاء الاصطناعي (`learn.wwl.build-automation-agent-integrations`)
- **الموديول 1:** `learn.wwl.implement-resilient-cloud-flows` — بناء تدفقات سحابية مرنة مع معالجة الأخطاء.
- **الموديول 2:** `learn.wwl.consume-dataverse-mcp-servers` — استهلاك خوادم Dataverse Model Context Protocol (MCP).
- **الموديول 3:** `learn.wwl.integrate-custom-agents-power-platform` — تكامل الوكلاء المخصصين مع Power Platform.

### 4. تكامل Dataverse مع الخدمات السحابية والبيانات الخارجية (`learn.wwl.integrate-dataverse-external-services`)
- **الموديول 1:** `learn.wwl.publish-dataverse-events` — نشر أحداث Dataverse لـ Webhooks و Azure Service Bus.
- **الموديول 2:** `learn.wwl.synchronize-external-data-dataverse` — مزامنة البيانات عبر تتبع التغييرات والمفاتيح البديلة.
- **الموديول 3:** `learn.wwl.build-power-platform-custom-connectors` — بناء موصلات مخصصة عبر مواصفات OpenAPI.

### 5. تصميم وتسليم حلول Power Platform الآمنة والمحكومة (`learn.wwl.design-deliver-power-platform-solutions`)
- **الموديول 1:** `learn.wwl.design-power-platform-architectures` — تصميم المعماريات الفنية للحلول المؤسسية.
- **الموديول 2:** `learn.wwl.design-power-platform-components` — تصميم المكونات البرمجية القابلة لإعادة الاستخدام.
- **الموديول 3:** `learn.wwl.deliver-solutions-governed-alm` — إدارة دورة حياة التطبيقات ALM والحلول المدارة و CI/CD.
